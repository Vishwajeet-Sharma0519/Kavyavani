# Kavyavani

The Expo / React Native application is in [`mobile/`](mobile/README.md). The original `kavya_merged_final.json` remains the read-only source dataset.

```powershell
cd mobile
npm ci
npm run web
```

For a production web build suitable for free static hosting:

```powershell
npm run build:web
npm run preview
```

Open http://localhost:4173. See the app README for mobile startup, deployment, testing, and known constraints.
